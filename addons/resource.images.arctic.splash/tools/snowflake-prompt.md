# Winter snowflake sprite

Generated with the built-in imagegen tool, with a transparent background.
The original is preserved in `tools/snowflake-source.png`. The rebuild scripts
fill its crystal branches and blur its alpha into soft, fluffy snow, shared by
the winter particles and the falling weather tile.
The runtime artwork is reduced to 64 x 64 pixels with transparent padding and
uses the existing scene-authoring grade function for eight lighting variants in
`resources/effects/foliage/winter/`. No animation frames are stored.

## Final prompt

Use case: illustration-story. Asset type: one tiny snowflake particle sprite for a hand-painted winter landscape animation in Kodi. Primary request: a single elegant six-armed snow crystal, centered and isolated on a genuinely transparent background. Pale icy white body with very subtle cool blue shading, softly painted edges, clear stout main arms and only one short pair of side branches per arm so it remains legible when reduced to 32–48 pixels. Straight-on view, balanced radial silhouette, modest dimensional texture matching painted nature artwork. Fill about 75 percent of a square canvas with generous transparent padding. No scene, no text, no decorative border, no drop shadow, no glow, no surrounding snow specks, no checkerboard painted into the image. Exactly one snowflake.
